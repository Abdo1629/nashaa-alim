# نشء – لنحيا بنور | دورة عالِم

واجهة تعريفية تفاعلية لدورة عالِم – الدفعة الثالثة، مبنية باستخدام React + TypeScript + Vite.

## تشغيل المشروع محليًا

```bash
npm install
npm run dev
```

## إعداد مساعد Gemini على Vercel

المساعد يستخدم Vercel Serverless Function في `api/chat.js`، لذلك لا تضع مفتاح Gemini داخل كود الواجهة أو داخل GitHub.

1. أنشئ مفتاح Gemini من [Google AI Studio](https://aistudio.google.com/app/apikey).
2. افتح مشروع الموقع في Vercel.
3. اذهب إلى **Settings → Environment Variables**.
4. أضف متغيرًا باسم `GEMINI_API_KEY` وضع قيمة المفتاح في خانة القيمة.
5. فعّل المتغير لبيئات Production وPreview حسب حاجتك، ثم أعد نشر المشروع (Redeploy).

ملف `.env.example` يوضح اسم المتغير المطلوب فقط، ولا يحتوي على مفتاح حقيقي.

> واجهة المحادثة تظهر على الموقع، لكن الردود الفعلية من Gemini تحتاج نشر المشروع على Vercel وإضافة متغير `GEMINI_API_KEY` أولًا.
